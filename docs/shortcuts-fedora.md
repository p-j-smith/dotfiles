# Shortcuts on Fedora

## Ghostty

| To... | Press |
|---|---|
| New tab / new window | Ctrl+Shift+T / Ctrl+Shift+N |
| Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab (or Ctrl+PageDown / Ctrl+PageUp) |
| Go to tab 1–8 / last tab | Alt+1…8 / Alt+9 |
| Show every tab, to pick one | Ctrl+Shift+Space |
| Split right / split down (new pane) | Ctrl+Shift+O / Ctrl+Shift+E |
| Move between panes | Ctrl+Alt+arrows, or Super+Ctrl+] / Super+Ctrl+[ for next / previous |
| Zoom a pane (press again to unzoom) | Ctrl+Shift+Enter |
| Resize a pane / make all panes equal | Super+Ctrl+Shift+arrows / Super+Ctrl+= |
| Close pane / tab / every other tab | Ctrl+Shift+X / Ctrl+Shift+W / Ctrl+Alt+T |
| Copy / paste | Ctrl+Shift+C / Ctrl+Shift+V |
| Reload the config | Ctrl+Shift+, |

## Zed

Zed has vim mode on. In its normal mode, as in Neovim (LazyVim):

| To... | Press |
|---|---|
| Split right / below | Space then \| / Space then - (or Ctrl+W v / Ctrl+W s) |
| Move between panes | Ctrl+H/J/K/L (or Ctrl+W h/j/k/l) |
| Previous / next tab | Shift+H / Shift+L (or gT / gt) |
| Close tab / every tab in the pane / everything else | Ctrl+W c / Ctrl+W a / Ctrl+W o |
| Swap panes / make them equal / resize | Ctrl+W x / Ctrl+W = / Ctrl+W + − < > |
| Zoom a pane (press again to unzoom) | Shift+Esc |

Zed's own shortcuts:

| To... | Press |
|---|---|
| Split in any direction | Ctrl+K then an arrow |
| Pick a tab from a list | Ctrl+Tab |
| Reopen the last closed tab | Ctrl+Shift+T |
| Project panel / agent panel / bottom panel | Ctrl+B / Ctrl+Alt+B / Ctrl+J |
| Terminal panel / new terminal | Ctrl+\` / Ctrl+~ (Ctrl+Shift+#) |

In Zed's terminal, Ctrl+Shift+5 splits right and Ctrl+Shift+W closes it.

## GNOME

| To... | Press |
|---|---|
| Switch app / window of the same app | Alt+Tab / Alt+\` |
| Overview and search | Super |
| Left half / right half / maximise / restore | Super+Left / Super+Right / Super+Up / Super+Down |
| Previous / next desktop | Super+PageUp / Super+PageDown (or Super+Alt+Left / Super+Alt+Right) |
| Move the window to the previous / next desktop | Super+Shift+PageUp / Super+Shift+PageDown |
| Switch keyboard layout (UK / Mac UK) | Super+Space |
| Sleep | Super+Shift+S |
