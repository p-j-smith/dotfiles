# Shortcuts on macOS

## Ghostty

| To... | Press |
|---|---|
| New tab / new window | ⌘T / ⌘N |
| Next / previous tab | ⌘⇧] / ⌘⇧[ (or ⌃Tab / ⌃⇧Tab) |
| Go to tab 1–8 / last tab | ⌘1…8 / ⌘9 |
| Split right / split down (new pane) | ⌘D / ⌘⇧D |
| Move between panes | ⌘⌥ arrows, or ⌘] / ⌘[ for next / previous |
| Zoom a pane (press again to unzoom) | ⌘⇧Enter |
| Resize a pane / make all panes equal | ⌘⌃ arrows / ⌘⌃= |
| Close pane (or the tab, if it has one pane) | ⌘W |
| Close tab / close window | ⌘⌥W / ⌘⇧W |
| Reload the config | ⌘⇧, |

## Zed

Zed has vim mode on. In its normal mode, as in Neovim (LazyVim):

| To... | Press |
|---|---|
| Split right / below | Space then \| / Space then - (or ⌃W v / ⌃W s) |
| Move between panes | ⌃H/J/K/L (or ⌃W h/j/k/l) |
| Previous / next tab | ⇧H / ⇧L (or gT / gt) |
| Close tab / every tab in the pane / everything else | ⌃W c / ⌃W a / ⌃W o |
| Swap panes / make them equal / resize | ⌃W x / ⌃W = / ⌃W + − < > |
| Zoom a pane (press again to unzoom) | ⇧Esc |

Zed's own shortcuts:

| To... | Press |
|---|---|
| Split in any direction | ⌘K then an arrow |
| Pick a tab from a list | ⌃Tab |
| Reopen the last closed tab | ⌘⇧T |
| Project panel / agent panel / bottom panel | ⌘B / ⌘⌥B / ⌘J |
| Terminal panel / new terminal | ⌃\` / ⌃~ |

In Zed's terminal, ⌘D splits right. Rectangle takes ⌃⌥ arrows for halves of the screen.
